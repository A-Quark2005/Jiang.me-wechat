# 讲了么小程序

这是独立业务小程序，不再作为安卓 `bindingTicket` 手机号绑定页使用。

## 当前能力

- 微信登录进入小程序。
- 腾讯会议激活。
- 会议权益：读取商品、创建小程序支付订单。
- 简历：管理我的认证、自我介绍、孪生服务履历。

## 约定

- 默认后端地址：`https://api.whkerdb.top`，集中配置在 `app.js`。
- 除微信登录外，请求都会携带 `Authorization: Bearer <token>`。
- 成功响应只接受 `{ ok: true, data }`。
- 不使用本地模拟业务数据；后端接口未就绪时页面直接展示真实错误。
